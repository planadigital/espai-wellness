# Espai Wellness Pàdel · Web

Web d'una sola pàgina (HTML, CSS i JavaScript, sense dependències) per a Espai Wellness Pàdel, Granollers.

## Contingut

- `index.html`: tota la web (Inici, Serveis, Galeria, Preus, Contacte; català i castellà).
- `img/`: imatges i vídeos (portada i club).
- `horari-espai-wellness.pdf`: horari corporatiu d'activitats dirigides.

## Com veure-la

Obre `index.html` al navegador, o serveix la carpeta amb qualsevol servidor estàtic:

```
python3 -m http.server 8000
```

Tipografies (Instrument Serif i Inter Tight) carregades des de Google Fonts.
